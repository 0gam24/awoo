# inbox — 운영자가 손으로 내려받은 파일을 넣는 곳

자동 수집이 안 되는(또는 하면 안 되는) 자료를 운영자가 직접 받아서 여기에 넣으면, 스크립트가 읽어 적재한다.

| 넣는 것 | 어디서 | 그다음 |
|---|---|---|
| 서치어드바이저 리포트 CSV (검색어 탭 · 문서 탭) | https://searchadvisor.naver.com → 웹마스터 도구 → 사이트 선택 → 리포트 → 기간 선택 → 내려받기 | `npm run advisor:import` → `src/data/search-advisor/search-advisor-<기간>.json` |

- **왜 손으로 받나:** 네이버 검색 화면은 robots.txt가 봇 수집을 막는다(2026-09-15부터 순위 측정은 공식 API만 쓴다). 서치어드바이저 리포트는 네이버가 사이트 주인에게 직접 주는 값이라, **사람이 보는 화면에서의 노출·클릭·평균순위를 아는 유일한 길**이다.
- **주기:** 주 1회면 충분하다. 기간은 지난 7일로 맞춘다.
- 적재가 끝나도 원본 CSV는 지우지 않는다. 확인한 뒤 직접 지워라.
- 열 이름을 못 알아보면 스크립트가 그 파일을 건너뛰고 헤더를 그대로 보여준다. 네이버가 양식을 바꿨다는 뜻이니 `scripts/ingest-search-advisor.mjs`의 `KEYS`에 이름을 한 줄 더한다.
