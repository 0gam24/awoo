# 네이버 최상단 노출 — 실측 근거와 전략

기준일 2026-09-08 · 운영자 지시로 **네이버가 주전장**이다(구글은 부차). 이 문서는 추측이 아니라 1차 출처 원문과 SERP 실측만 담는다. 확인 못 한 것은 그렇게 표시했다.

## 0. 결론 먼저

awoo의 네이버 문제는 색인도, 본문 길이도, 구조화 데이터도 아니다. **이미 색인은 당일 되고, 본문은 상위 경쟁 문서보다 길고, JSON-LD는 압도적이며, 네이버는 awoo에 AI 출처 정보까지 붙여 신뢰 엔티티로 취급하고 있다.**

실제 격차는 셋이다.
1. **제목이 검색 쿼리가 아니다** — 이긴 자리와 진 자리를 가른 유일한 변수
2. **RSS가 요약만 담아 네이버 공식 요구사항을 어기고 있었다** (2026-09-08 전문 발행으로 해결)
3. **SERP의 55%가 네이버 자사 UGC라 외부 문서가 못 들어가는 자리가 대부분이다** — 들어갈 수 있는 자리를 고르는 것이 승부

## 1. 네이버 공식 조건 (1차 출처 원문 확인)

`searchadvisor.naver.com/guide` 및 네이버 검색 공식 블로그에서 직접 확보. WebFetch는 두 도메인 모두 차단되므로 **Bash curl**을 써야 한다.

| 항목 | 원문 요지 | 문서 |
|---|---|---|
| 검색로봇 | UA `Yeti`. IP 차단 금지, robots.txt로 제어 | seo-basic-intro |
| **RSS 전문 발행** | "각 item의 본문은 일부가 아닌 **모든 내용(본문 전체 공개)**". 웹마스터도구에 **"요청 > RSS 제출" 메뉴 존재** | request-feed |

| 연관채널 | Organization/Person + **`sameAs` 필수**. 채널 간 링크를 클러스터링해 랭킹에 활용 | structured-data-channel |
| 콘텐츠 5원칙 | 전문성·경험 / 일관된 주제 / 진정성·원문 출처 표기 / 읽기 쉬운 구조(**핵심은 반드시 텍스트로**) / 최신성 | content-basic |
| **웹 콘텐츠 스팸** | **만료 도메인 악용**, **저품질 콘텐츠 대량 생성**(동일·유사 템플릿 대량 발행, 문장 일부만 바꾼 페이지 수십 개 이상). "AI 활용 여부만으로는 판단하지 않음" | 공식블로그 2026-07-06 |

| AI 출처 정보 | 2026-05-14 공공·교육·공익 공식 블로그 우선 제공, 대상 확대 중 | 공식블로그 2026-05-07 |
| 연관검색어 | **2026-04-06 서비스 종료** | 공식블로그 2026-04-06 |

**awoo에 직결**: 네이버가 스팸으로 명시한 "만료 도메인 악용"과 "동일 템플릿 대량 발행"은 구글 억제 진단(중고 도메인 + 구조 지문)과 **같은 두 축**이다. 구글만의 문제가 아니었다.

### 확인 못 한 것 (추측 금지)

- **C-Rank / D.I.A. / D.I.A.+** — 공식 설명 문서가 **없다**. 시중 설명은 전부 3자 해석이고, 이들은 **네이버 블로그 랭킹 로직**이라 외부 웹문서 적용 근거를 찾지 못했다. **판단 기준으로 쓰지 마라.**
- **AI 브리핑 인용 선정 기준** — 공식 문서 없음. 본문·출처가 클라이언트 렌더라 정적 fetch로 확인 불가.
- **스마트블록 블록명** — 클라이언트 렌더. 영역 코드(`urB_boR`, `urB_b1~3R`, `urB_coR`)만 확보.

### awoo가 실제로 잡혀 있는 자리

`실업급여 조기재취업수당 조건` **웹문서 블록 6개 중 5위**, 모든 네이버 블로그보다 위:

```
1~4위  고용노동부·고용보험·정부24 (go.kr)
5위    ★ awoo.or.kr — 조기재취업수당 조건 2026, 12개월 근속·신청기한
```

> **2026-09-09 정정.** 위 문장을 "awoo가 이긴 유일한 자리"로 읽으면 **틀린다.**
> 그때는 이 6개 쿼리만 재 봤을 뿐이다. 순위 측정기를 만들어 14개를 재니 **7건 노출,
> 3위 이내 5건, 1위 3건, 평균 2.4위**였다. 상세는 §3-1.
>
> 다만 **1위 3건은 자축할 근거가 못 된다.** 그 쿼리들은 우리 글 제목에서 뽑은
> 것이라 제목-쿼리 일치가 애초에 보장돼 있었다. **그 쿼리를 실제로 검색하는
> 사람이 있는지는 아직 확인되지 않았다** — 검색량 0인 쿼리의 1위는 값이 0이다.
> 다음 과제는 순위가 아니라 **그 순위에 트래픽이 붙는지** 확인하는 것이다.

- 사이트명이 **"지원금가이드"**로 정규화 표시
- **AI 출처 정보 부여** — 원래 공공기관 공식 블로그 대상이던 기능. 네이버가 awoo를 신뢰 엔티티로 인식한다는 증거
- 다만 설명이 awoo를 "맞춤 지원금 추천 서비스"로 규정 — 이슈 매체로는 아직 인식되지 않음(개선 여지, 추측)

## 3. 실행 규칙

1. **제목은 타깃 쿼리를 그대로 맨 앞에.** 연도·의문형을 앞세우지 마라. 키워드 반복은 1회만.
2. **발행 전 반드시 SERP 실측.** 외부 웹 0건인 쿼리는 버린다(`naver-serp-scout`).
3. **RSS 전문 유지.** `/feed-issues.xml`은 `content:encoded`로 본문 전체를 내보낸다(2026-09-08 적용). 서치어드바이저 "요청 > RSS 제출" 등록은 운영자 몫.
4. **저품질 페이지 색인 금지.** 토픽 허브는 보유 글 3건 미만이면 noindex, 빌드 후 sitemap에서도 제거(`scripts/prune-sitemap-noindex.mjs`).
5. **지역 템플릿 3조건** — 그 지자체 공고에만 있는 사실 2개 이상 / 주 3건 이하 / 본문 1,500자 이상.
6. **네이버 어뷰징 금지** — 매크로·계정 대량 운영·링크 구매·클릭 조작. 스팸 명문화 항목이라 도메인이 통째로 빠진다.

## 3-1. 에이전트 팀과 일일 루프 (2026-09-09 구축)

`/naver-daily`가 하루 한 바퀴를 돈다. 이전 파이프라인에 없던 것은 **1단계(측정)** 다.
측정 없이 반복하면 같은 실수를 무한히 반복한다.

```
① 성적 측정   naver-rank-tracker      어제 발행분 실제 순위 + 원인 진단 + 교정안
② 후보 발굴   emerging-keyword-hunter  신생·틈새 (blogTotal 작은 자리)
             cluster-auditor          과포화 클러스터 차단        [①②는 병렬]
③ SERP 실측   naver-serp-scout        외부 웹 0건인 쿼리는 버림
④ 작성       post-writer              제목=쿼리, targetQuery 필수
⑤ 검증       naver-content-shaper / fact-checker / google-quality-auditor  [병렬]
⑥ 거부권     publish-gatekeeper       VETO면 발행 없음
⑦ 결재 → 발행
```

**루프를 잇는 것은 `targetQuery` 필드 하나다.** 포스트가 이 필드를 선언하면
`scripts/naver-rank-check.mjs`가 다음날 자동으로 측정 대상에 넣는다. 빠뜨리면
그 글의 성적을 영영 알 수 없고 루프가 거기서 끊긴다.

### 순위 측정

```bash
npm run rank:check                                   # 전체(25건 상한)
node scripts/naver-rank-check.mjs --query="..."      # 단건
```

통합검색 HTML을 직접 받아 `fds-web-doc-root` 컨테이너를 세어 순위를 뽑는다.
요청 간 3초·1회 25건 상한. 매일 KST 09:40에 `naver-rank.yml`이 자동 실행한다.

- **`externalCount: 0`이면 우리 잘못이 아니다.** 외부 사이트가 구조적으로 못 들어가는
  자리이니 글을 고칠 게 아니라 쿼리를 버려야 한다.
- **`parseOk: false`는 "순위 없음"이 아니라 "못 읽음"이다.** 네이버가 SERP 구조를
  바꿨다는 뜻이므로 0위로 집계하면 안 된다.

### 첫 측정 (2026-09-09, 14건) — 기준선

**노출 7/14 · 3위 이내 5 · 평균 2.4위**

```
1위/10   공익직불금 이행점검 감액
1위/5    혼인지원금 혼인신고 시점
1위/5    기초연금 2027 개편 부부
2위/11   나주 민생회복지원금 5부제
3위/9    노란우산공제 소득공제 한도
4위/6    배우자 유산 사산휴가 유급
5위/7    실업급여 조기재취업수당 조건
미노출    에너지바우처 잔액 조회 / 청년월세 주거급여 중복 /
         기초연금 수급자격 소득인정액 계산 / 국가장학금 서류제출 안 하면 /
         본인부담상한액 초과금 환급 / 참전명예수당 2027 인상 /
         근로장려금 반기신청 지급일(외부 웹 0건 — 구조적 불가)
```

**갈린 선이 뚜렷하다.** 이긴 7건은 전부 우리 글 제목에서 뽑은 구체적 롱테일이고,
진 6건(구조적 불가 1건 제외)은 전부 일반적·광의 쿼리다.

**그러나 이 표본은 편향돼 있다.** 후자 7개 쿼리는 우리 제목에서 역산한 것이라
제목-쿼리 일치가 처음부터 보장돼 있었다. **검색량 검증이 없으면 1위 3건은 의미가
확정되지 않는다.** 다음 회차 과제는 이 쿼리들의 실제 검색량을 데이터랩으로 재고,
검색량 있는 쿼리만 타깃으로 남기는 것이다.
