## 1. 네이버 하한선 (절대 불변 — 이 아래로 내려가지 않는다)

현 트래픽을 만드는 요소. 다양화는 **이 위에서 문형·순서·구성만** 회전한다.

1. **answer 직답 1문장** (수치+날짜, ≤120자, 최상단) — 지식스니펫·AI 브리핑·구글 스니펫 공통 이득
2. **coreFacts 4수치**(who/amount/deadline/where) 첫 화면 접근성 — 값은 유지, 렌더 문형만 변주 가능
3. **표 관련 규칙**: 비교·수치 구조화가 필요한 글엔 표 1개(셀 수 일치). 단일 수치 주제는 생략 가능 (→ §2)
4. **FAQ ≥3 + FAQPage 스키마**
5. **title·tags에 지역명+제도명+금액 토큰** (브로드 헤드 금지 — 2026-07-09 지시 유지)
6. **updates[]·dateModified 갱신 신호** + 발행일/수정일 가시 표기
7. **sources ≥3, 정부 1차 출처(go.kr) ≥1**, 본문 인라인 인용
8. **C-Rank 주제 집중**: 지원금 단일 토픽 유지 (카테고리 화이트리스트 불변)
9. **발행 24h 내 네이버 수집 요청** (시기성 글 필수)

## 2. 구조 프로파일 로테이션 (신규 글 핵심 규칙)

글마다 작성 **전에** 구조 프로파일을 굴려 정하고, 그 프로파일대로 쓴다. 직전 발행 5건과 같은 프로파일 금지.

| 축 | 허용 범위 | 금지 |
|---|---|---|
| tldr | **3~6개** (주제 복잡도 따라) | 5개가 습관값이 되는 것 — tldr 5·faq 5 동시 조합은 lint warn |
| faq | **3~7개** | 5개 고정. 후속 질문·예외·경계조건만 (본문 재복사 금지) |
| sections | **3~7개**, 문단수 2~6 가변 | 3섹션·3문단 고정 |
| table | 비교·구간·지역차가 있을 때만 (열 구성·행수·위치 가변) | 습관성 표. 단일 수치 글은 본문 리스트로 |
| H2 heading | **질문형 40~60% + 명사형·수치형 혼합**. 코퍼스 기존 heading과 완전일치 금지(lint warn) | 전면 질문형(현재 99%), "얼마를 받을 수 있나요?" 류 재사용 |
| 절차 서식 | 4종 로테이션: ①번호 단계 ②산문 서술 ③체크리스트 ④2열 표 | "1단계:→2단계:→3단계:" 리터럴 연속 사용 (현재 82%) |
| metaDescription | 종결형 로테이션: 수치 제시형·질문형·마감 카운트다운형·조건 요약형 등, 1~3문장, 60~110자 | "~정리했습니다" 종결 (현재 62%) |
| answer 문형 | 결론 선행형 / 조건 선행형 / 기한 선행형 로테이션 | 단일 문형 고착 |
| title | 4패턴 로테이션: 콤마형("A 2026, B") / 명사구형 / 수치선행형 / 의문형. 숫자 포함 유지(CTR), 위치는 앞·중간·뒤 로테이션 | 콤마형 단일 공식, "총정리" 마지막 단어 남용 |
| publishedAt | **분·초 랜덤** | 정각·30분 발행 (현재 02:00이 32%) |
| relatedSubsidies | 최근 30일 글과 세트 완전일치 금지 (최소 1개 교체) | 동일 세트 재사용 (현재 최대 14건 중복) |

## 3. 정보 이득 요구 (Information Gain — GOOGLE_CONTENT_PROMPT PART 04·05 이식)

신규 글은 공식자료 요약을 넘어 **원본 가치 요소 ≥2개**를 반드시 포함한다.

허용 요소(택2+): 자체 계산(예: 가구·조건별 실수령 시뮬레이션) · 새 비교 기준(경쟁 문서에 없는 비교표) · 조건별 시나리오(A조건이면 X, B조건이면 Y) · 마찰 지점 분석(전입일·기준일·중복수급 등 실제로 막히는 곳) · 교차 종합(서로 다른 1차 자료 연결) · 타임라인(제도 변화 흐름) · 판단 프레임(독자가 스스로 판정하는 기준)

금지 (패딩 문구를 정보의 대체물로 사용):
- "지역마다 다를 수 있습니다" / "상황에 따라 달라질 수 있습니다" / "공식 홈페이지를 확인하세요" 단독 사용 — 쓰려면 **구체 확인 경로·기준을 함께** 제시
- 확정 팩트 0건 발행: **금액·마감 중 최소 1개 확정 수치 없으면 발행 보류**(radar 대기열로) — lint err

FACT/해석/추정 구분(PART 08): 추정은 "~로 추정(근거)", 해석은 사실 뒤에. 가짜 경험("직접 해보니") 절대 금지(기존 규칙 유지).

기준일 표기(PART 10): 시간 민감 주제는 본문에 "기준: YYYY-MM-DD 발표/공고" 명시 — updates[]와 연동.

## 5. 발행 속도·구성 정책 (도메인 신뢰 회복기)

구글 색인률이 회복(신규 글 색인률 30%+)될 때까지:

- **신규 하루 1~3건** (기존 상한 8건 → 축소). 갱신(updates)은 무제한 — 신규보다 갱신 우선
- **지역명 치환 동시 발행 금지**: 같은 날 동일 템플릿 지역 변형 N건 연발(8/19 4연발 패턴) 대신, 지역 비교 허브 1건 + 필요 시 이후 날짜 분산. 지역 단건은 **지역 고유 사실**(조례·재원·인접 비교·지급 수단 차이) 비중 확보 — 네이버 유사문서 정책과도 겹치는 순이득 지점
- **1키워드 1페이지**: 신청방법/일정/금액표 분할 발행(doorway) 금지 — 하위 주제는 섹션으로 통합
- 발행 시간대 주간(08~22시) 분산 권장, 분·초 랜덤

## 7. 에이전트 팀 v2 (검증 체인)

```
keyword-scout → longtail-strategist (GATE-A/B + 1키워드 1페이지)
  → post-writer (v2: 구조 프로파일 + 정보 이득 ≥2)
```
