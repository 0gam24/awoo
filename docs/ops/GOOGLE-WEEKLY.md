# 구글 주간 기록

매주 한 번 서치콘솔(도메인 속성 awoo.or.kr)에서 아래 값을 옮겨 적는다. 금액은 적지 않는다.

- 색인·미색인: 색인 생성 > 페이지
- 읽으러 온 횟수: 설정 > 크롤링 통계 (90일 합계와 검색 로봇 몫)
- 노출·클릭: 실적 > 최근 28일
- 사이트맵 쪽수: 색인 생성 > Sitemaps 의 sitemap-0.xml

## 읽는 법

- 먼저 움직여야 할 숫자는 "발견만 됨"이다. 줄어들면 구글이 다시 읽으러 오기 시작한 것이다.
- 색인 수가 줄어드는 것은 정리의 결과라 나쁜 신호가 아니다. 노출이 같이 줄지 않는지만 본다.
- 4주 연속 "발견만 됨"과 노출이 그대로면 다음 단계(지원금 상세 쪽·용어 사전 정리, 옛 글 구조 손질 확대)로 넘어간다.
- 2027년 2월까지 회복이 없으면 새 도메인 이전을 검토한다(docs/ops/GOOGLE-NAVER-DUAL-STANDARD.md §6).
